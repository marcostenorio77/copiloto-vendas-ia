# Copiloto de Vendas com IA para Atendimento ao Cliente

## Sobre o Projeto

Este projeto apresenta um Copiloto de Vendas com IA desenvolvido para auxiliar vendedores de uma loja de informática durante o atendimento ao cliente.

A solução foi criada para apoiar a identificação das necessidades do cliente, sugerir produtos adequados e oferecer respostas para dúvidas frequentes.

## Tema Escolhido

Loja de Informática (TechStore)

## Usuário Principal

* Vendedores
* Atendentes
* Equipe comercial

## Problema Resolvido

Muitos clientes não sabem qual produto atende melhor suas necessidades.

O copiloto auxilia o vendedor fornecendo sugestões de produtos, respostas rápidas e argumentos comerciais.

## Abordagem Utilizada

Copiloto de Vendas baseado em uma base de conhecimento composta por:

* Contexto do negócio
* Produtos
* Perguntas frequentes
* Objeções comuns

## Base de Conhecimento

Arquivos utilizados:

* knowledge/contexto-negocio.md
* knowledge/produtos.md
* knowledge/perguntas-frequentes.md
* knowledge/objecoes.md

## Exemplo de Conversa

### Cliente

Preciso de um notebook para programação e faculdade.

### Resposta da IA

Recomendo um notebook intermediário com SSD e pelo menos 8 GB de RAM. Esse perfil oferece bom desempenho para estudos, programação e atividades acadêmicas.
